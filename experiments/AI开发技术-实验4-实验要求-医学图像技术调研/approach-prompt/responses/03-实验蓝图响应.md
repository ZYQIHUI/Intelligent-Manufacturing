### 1️⃣ Baseline 选择

我建议选择 **Medical SAM Adapter (SAM-Adapter)** 结合 **MedSAM** 的预训练权重作为你的基础 Baseline。

* **选择理由：**
* **性能与基础：** MedSAM 在超过 150 万张医学图像上进行了训练 ，虽然其通用性极强 ，但面对极微小的眼底微动脉瘤仍有不足。SAM-Adapter 则通过轻量化微调技术证明了在特定医疗领域超越原始 SAM 的能力。
* **适配难度与显存：** 直接微调庞大的原始 SAM（数亿参数）不仅容易过拟合，对算力要求也极高。Adapter 机制仅微调极少比例的参数，使得在单张 RTX 3090/4090 上进行完整实验成为可能。
* **代码开源情况：** 两者的代码均高度开源且社区活跃，PyTorch 实现非常标准，极其适合作为二次开发的基座。
* **备选建议：** 如果你的算力非常有限，可以考虑 **MobileSAM** 结合轻量级微调；如果你专注比较传统的无 Prompt 网络，**RTNet** 是最好的对比锚点。

### 2️⃣ Baseline 架构详解 (基于 SAM-Adapter + MedSAM)

该 Baseline 的核心思想是“冻结大脑，训练外挂”。

* **整体架构：**
1. **Image Encoder (图像编码器)：** 基于大模型 ViT，负责提取高维图像特征。
2. **Prompt Encoder (提示编码器)：** 处理点 (Point) 或边界框 (Bbox) 等提示信息 。
3. **Mask Decoder (掩码解码器)：** 将图像特征和提示特征融合，输出最终的分割概率图 。




* **核心模块与设计原理 (相较于原始 SAM 的改动)：**
* **Adapter 插入：** 在 ViT 的每个 Transformer Block（注意力层和 MLP 层之后）插入了轻量级的 Adapter 模块（通常由降维线性层、激活函数、升维线性层组成）。
* **参数冻结：** 训练时，**冻结**原始 SAM/MedSAM 庞大的图像编码器权重，**仅更新** Adapter 模块和 Mask Decoder 的权重。
* **为什么这样设计？** 原始 SAM 缺乏医学图像的纹理和边界先验。通过注入 Adapter，网络可以在不破坏原本强悍的自然图像特征提取能力的前提下，低成本地学习眼底病变特有的特征分布。

### 3️⃣ 改进方案设计 (你的核心创新点)

针对第二轮分析的三大痛点，你的 EA-SAM 可以从以下路径进行创新：

* **改进模块一：图像增强先验注入 (解决“图像质量退化”)**
* **技术路线：** 借鉴 DiffCode 的思路，利用高质量特征字典 (VQ Codebook) 来补偿低质量眼底图像中丢失的细节 。具体来说，在图像输入 SAM 之前，使用高效的 NAF Block  构建一个轻量级的特征增强网络。提取的增强特征不直接输出图片，而是与 SAM 浅层的特征图进行通道拼接 (Concatenation) 融合。


* **预期解决：** 缓解眼底光照不均和白内障模糊导致的特征丢失，为 SAM 提供更锐利的病灶边缘梯度。


* **改进模块二：形变自适应 Adapter (解决“微小/不规则病变分割塌陷”)**
* **技术路线：** 将标准的线性 Adapter 替换为 **Deformable Adapter (形变适配器)**。引入可形变的卷积层 (Deformable Convolutions) 来代替普通线性映射。
* **预期解决：** 标准 ViT 的固定网格划分极易忽略仅占几像素的微动脉瘤。形变机制能自适应地将感受野“扭曲”并聚焦于细长或不规则的渗出物和出血点边缘。


* **改进模块三：无监督自动化 Prompt 生成 (解决“Prompt 机制失效”)**
* **技术路线：** 设计一个轻量级的 Bbox 生成头 (Bbox Generator Head)。利用 SAM 冻结编码器输出的中间层特征，经过一个简单的卷积层回归出粗略的病变边界框。随后将这些生成的框作为 Prompt 自动喂给 MedSAM 的 Prompt Encoder 。


* **预期解决：** 彻底摆脱人工点选/框选，实现端到端的全自动微小病变分割。

### 4️⃣ 实验配置

* **数据集选择：** **IDRiD**
* **原因：** 虽然数据量（516张）少于 DDR，但它提供极高质量的**像素级**多类别病变标注（微动脉瘤、出血、渗出等），分辨率超高（4288 × 2848），极其适合验证微小病变（MA）的分割精度上限。
* **数据划分：** 遵循业界标准，54 张作为训练集，27 张作为测试集（针对有分割 Mask 的 81 张图像）。


* **评估指标：**
* **Dice 系数 (DSC)：** 衡量整体分割重叠度，是核心指标 。


* **Sensitivity (敏感度)：** 衡量微小病变（如微动脉瘤）是否被漏诊。
* **Intersection over Union (IoU)：** 对边界贴合度要求更严苛的指标。


* **实验环境与超参数建议：**
* **框架与硬件：** PyTorch 框架 ；单张或多张 NVIDIA A100/RTX 4090/3090 GPU 。


* **优化器与学习率：** 使用 Adam 优化器 ，初始学习率可设为 $2 \times 10^{-4}$，配合余弦退火 (Cosine Annealing) 衰减至 $1 \times 10^{-6}$ 。


* **Batch Size：** 由于图像分辨率高且 ViT 显存占用大，建议使用较小的 Batch Size (如 2、4 或 8) ，配合梯度累加 (Gradient Accumulation) 技术。


* **损失函数：** Dice Loss  + 交叉熵损失 (BCE Loss) 的加权组合。




* **对比方法 (Baselines for comparison)：**
1. 传统深度学习 SOTA：DeepLabv3+, RTNet
2. 通用医学基础模型：MedSAM 


3. 迁移学习适配模型：Medical SAM Adapter
4. 眼底专精方法：GlanceSeg


* **消融实验 (Ablation Study) 必不可少：**
* Baseline (纯 SAM-Adapter)
* Baseline + 增强先验注入
* Baseline + 自动 Prompt 生成
* Baseline + 增强 + 自动 Prompt + 形变 Adapter (Ours 完整版)
