# 实验四 — 医学图像技术调研

对医学图像分析领域的前沿技术进行文献调研，涵盖眼底视网膜病变分割与医学图像增强两个子方向。

## 技术栈

深度学习（CNN, Transformer）, SAM, 图像分割, 图像增强, 文献综述

## 核心内容

- **眼底视网膜病变分割** — 糖尿病视网膜病变病灶分割相关论文 9 篇（2020-2025）
- **医学图像增强** — 多疾病医学图像修复/增强论文 5 篇（2024-2026）
- **其他方向** — SAM 模型应用与蒸馏相关论文
- **交付物** — 技术调研报告（DOCX）
