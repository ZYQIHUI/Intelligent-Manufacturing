## 职位详情

### A — 架构分析师

- **工作范围**：步骤 3（项目结构与七层架构分析），纯静态分析
- **关键任务**：
  1. 梳理 `src/` 下 7 个子目录的项目结构
  2. 阅读核心源码（server、agent、tools、sandbox、db）
  3. 深入分析知识库（选一个概念完整阅读）
  4. 绘制**系统结构图**（七层架构 + 数据流向）
  5. 绘制**学习闭环流程图**（10 个节点 + API + 模块标注）
  6. 撰写架构分析文档
- **产出**：项目结构表、知识库概念分析、系统结构图、流程图、架构分析文档

### B — 部署与沙箱测试员

- **工作范围**：步骤 0、1、2、4、5 的测试部分，唯一要完整运行系统的人
- **关键任务**：
  1. 编写一键安装脚本 + 录屏
  2. 环境信息记录 + 系统启动
  3. 完整跑一遍学习闭环（诊断→聊天→提交代码→查进度）
  4. **6 类沙箱测试**：正常输出、语法错误、运行时错误、超时、越权访问、pytest 评测
  5. 沙箱安全配置记录（网络、内存、PID、能力、文件系统、超时）
  6. 运行单元测试和学生回路测试
  7. **5 类风险验证**：提示注入、越权工具调用、不安全代码执行、XSS、隐藏测试泄露
  8. 数据库表内容记录
- **产出**：安装脚本、部署录屏、环境信息、启动日志、截图、沙箱测试记录、安全配置、测试日志、风险验证、数据库说明

### C — 实验报告撰写员

- **工作范围**：步骤 6.1（报告撰写），小组枢纽
- **关键任务**：
  1. 收集并阅读 A/B 所有产出
  2. 撰写报告大纲（7 章结构）
  3. 撰写报告主体（5000-8000 字），嵌入截图和图表
  4. **回答 8 个总结问题**（每个 300-500 字，结合实证）
  5. 撰写实验心得（500-1000 字）
  6. 整理附录 -> 交叉审阅 -> 格式定稿
- **产出**：报告大纲、实验报告草稿、八问回答、实验心得、附录清单、最终报告（.md/.docx/.pdf）

### D — PPT 制作员

- **工作范围**：步骤 6.3（制作 PPT）
- **关键任务**：
  1. 从 A/C/B 收集素材
  2. 设计 PPT 大纲（12-15 页）
  3. 制作 PPT（架构图、流程图、沙箱截图网格、八问网格）
  4. 编写演讲者备注（每页 100-200 字）
  5. 交叉审阅 -> 定稿 -> 导出 PDF
  6. 准备汇报速查表
- **产出**：PPT 大纲、草稿、演讲者备注、定稿 PPT（.pptx/.pdf）、图片版、速查表

### E — 汇报员

- **工作范围**：步骤 6.3 末尾 + 现场汇报，最终呈现者
- **关键任务**：
  1. 通读所有材料（任务文档、报告、PPT、源码背景）
  2. 写讲解稿（8-12 分钟）
  3. **Q&A 准备**（15+ 问题）
  4. 至少演练 3 次
  5. 汇报当天设备检查
  6. 现场汇报
  7. 汇报后复盘
- **产出**：阅读笔记、体验截图、讲解稿、Q&A 准备、演练记录、复盘笔记
