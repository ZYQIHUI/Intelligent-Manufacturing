# 职位 4：PPT 制作员

## 你的身份
你是 5 人小组中的**PPT 制作员**，代号 **D**。你的核心职责是基于 A 的图和 C 的报告，制作一份**视觉清晰、结构合理、便于汇报**的演示文稿。

## 项目背景
- 实验名称：Python 程序设计课程学伴 Agent
- 项目路径：`coding-mentor-agent/`
- 实验任务文档：`实验5.agent程序设计案例.txt`
- 实验步骤文档：`实验步骤.md`
- 项目仓库：https://github.com/xixu-me/coding-mentor-agent

## 你的工作范围
对应实验步骤文档的**步骤 6.3（制作 PPT）**。你**不需要**启动系统。

## 具体任务清单

### 任务 0：素材收集
- 完整阅读 `实验5.agent程序设计案例.txt`（了解评分点）
- 完整阅读 `实验步骤.md`（了解整体结构）
- 从 A 处获取：
  - `小组分工/A-产出/03-系统结构图.png`（高分辨率）
  - `小组分工/A-产出/04-学习闭环流程图.png`（高分辨率）
- 从 C 处获取：
  - 报告定稿 `小组报告/实验报告.md`
  - 八问回答的精炼版（每问 100 字以内）
- 从 B 处获取精选截图：
  - 部署 2 张（终端 + 浏览器主页）
  - 沙箱 6 张（6 类代码）
  - 学习闭环 2–4 张（诊断、聊天、提交、进度）
  - 单元测试 1 张
  - 学生回路测试 1 张

把素材归整到：`小组分工/D-产出/00-素材汇总/`

### 任务 2：PPT 母版与配色
- 工具：PowerPoint / Keynote / WPS / Google Slides
- 推荐：
  - 配色：浅色背景 + 强调色（蓝色或绿色）
  - 字体：标题用思源黑体/微软雅黑加粗；正文用思源黑体/微软雅黑
  - 字号：标题 28–32pt；正文 18–22pt；注释 14–16pt
  - 每页不超过 6 行文字
- 统一页眉：项目名称 / 小组名
- 统一页脚：页码

### 任务 3：制作 PPT
- 输出：`小组分工/D-产出/02-实验PPT-草稿.pptx`
- 制作要点：
  - 架构图页（页 6）：用 A 的图，放大占满
  - 流程图页（页 9）：用 A 的图，加动画逐节点出现
  - 沙箱页（页 10）：用 2×3 或 3×2 网格展示 6 张代码截图
  - 八问页（页 13）：用 2×4 网格，每格 1 问
- 避免：
  - 大段文字堆砌
  - 低分辨率图片
  - 花哨的过渡动画
  - 颜色超过 3 种

### 任务 4：演讲者备注
- 在 PPT 每页添加"演讲者备注"
- 内容：E 汇报时该说什么
- 字数：每页 100–200 字
- 输出包含在 PPT 文件的备注中
- 也可单独输出：`小组分工/D-产出/03-演讲者备注.md`

### 任务 5：交叉审阅
- 把 PPT 草稿发给所有人看
- A 重点审：页 6–9（架构、流程、知识库）
- B 重点审：页 5、10、12（部署、沙箱、测试）
- C 重点审：页 13–14（八问、心得）
- E 重点审：演讲节奏、可读性
- 收集意见后修改

### 任务 6：定稿
- 输出：`小组报告/实验PPT.pptx`
- 同时导出：`小组报告/实验PPT.pdf`（备用）

### 任务 7：汇报演练支持
- 把 PPT 转成图片版（`小组报告/实验PPT-图片版/`）备用
- 准备一份"汇报速查表"：1 页 A4 大小的核心要点清单
- 输出：`小组分工/D-产出/04-汇报速查表.pdf`

## 验收标准
1. 页数 12–15
2. 架构图和流程图清晰可见
3. 6 张沙箱截图齐全
4. 8 问每问 1–2 句精炼
5. 配色统一，无错别字
6. .pptx 和 .pdf 双格式
7. 演讲者备注齐全

## 设计技巧
- **图标**：用图标库（如 Font Awesome、IconPark）增加视觉
- **数据可视化**：测试结果页可用饼图/柱状图
- **对比表**：8 问中"已验证/未验证"可用左右对比
- **配色建议**：
  - 主色：#2E5BBA（深蓝）
  - 辅色：#4CAF50（绿，强调成功）
  - 警示：#F44336（红，强调风险）
  - 背景：#FFFFFF / #F5F5F5
