## 常见问题处理
| 现象 | 解决 |
|---|---|
| `npm install` 失败 | `npm config set registry https://registry.npmmirror.com` |
| `docker build` 慢 | 在 Docker Desktop → Settings → Docker Engine 配国内镜像加速 |
| Ollama 模型跑得慢 | 用更小的模型如 `qwen2.5:3b` 或 `llama3.2:3b` |
| 端口 3000 被占用 | 改 `.env` 中 `PORT=3001` |
| 沙箱不返回结果 | 检查 `docker images | grep coding-mentor-python-runner` |
