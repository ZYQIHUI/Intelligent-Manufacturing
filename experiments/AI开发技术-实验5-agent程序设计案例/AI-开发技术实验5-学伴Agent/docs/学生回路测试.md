## 学生回路架构

### 回路策略层次

```
学生回路
├── 本地模式 (test:student-loop:local)
│   └── 单次运行，localhost，证据模式=local_only
├── 严格矩阵模式 (test:student-loop:strict)
│   └── 9个必选场景，probe_only模式，收敛条件=2次clean sweep
├── 真实发现模式 (test:student-loop:realistic)
│   └── 5种personas × 8+提示 × 突变，live_provider=true
├── 全现实闭合 (test:student-loop:full-realistic)
│   └── 7个oracle层，tutor-agent轴覆盖，直到clean
├── 安全模式 (test:student-loop:security)
│   └── prompt注入probe，隐藏答案probe，系统提示probe
└── 发布模式 (test:student-loop:release)
    └── 发布前最终检查
```

## 修复回路机制

根据 `student_loop_policy.json`：

- **最大修复迭代次数**: 3次
- **一次一个根因**: "one root cause per iteration"
- **修复账本**: `repair-ledger.jsonl`（记录finding → minimal_reproduction → targeted_verification）
- **修复后验证**: 仅重跑受影响的严格场景（非全矩阵重跑）
- **闭合条件**: 连续2次clean sweep
- **闭合声明**: "inside the declared coverage universe"（不声称无bug）
