## 失败测试详细分析

### `student-loop-protocol.test.ts` — 9个失败

所有失败均非代码缺陷，属于环境/文档缺失：

**A. 缺少文档文件（6个失败）**

```
ENOENT: docs/student-loop-protocol.md
```
涉及测试：
- `documents execution boundaries, canonical command, and repair gate`
- `exposes a portable local-only student loop command`
- `defines a best-boundary coverage adequacy model and bounded closure wording`
- `exposes default live realistic, local-only, strict, release, and security command boundaries`
- `separates repair iteration verification from final closure`

这些测试验证 `docs/student-loop-protocol.md` 文件存在且包含规定的协议定义，属于项目文档完整性问题。

**B. 缺少OpenSpec规范文件（2个失败）**

```
ENOENT: openspec/specs/student-loop-protocol/spec.md
ENOENT: openspec/specs/kb-grounded-autonomous-tutor-agent/spec.md
```
涉及测试：
- `defines a concrete student-loop-protocol purpose and expanded repair checklist`
- `defines a concrete tutor-agent purpose and repair checklist fields`

这些测试验证OpenSpec规范文件存在，属于开发规范文档缺失。

**C. 缺少Python E2E依赖（1个失败）**

```
ModuleNotFoundError: No module named 'playwright'
```
涉及测试：
- `validates realistic discovery policy, live preflight, actor policy, and oracle layers without launching a browser`

该测试通过子进程调用Python脚本 `tests/e2e/student_loop_discovery.py`，但playwright未安装，属于Python测试环境缺失。
