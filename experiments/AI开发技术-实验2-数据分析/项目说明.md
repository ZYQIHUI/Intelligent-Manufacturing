# 就业状态分析与预测 — 项目说明

> **课程**：AI开发技术 - 实验2 - 数据分析及可视化  
> **题目**：第十七届"华中杯"C题 — 就业状态分析与预测  
> **数据**：宜昌地区5000名被调查者脱敏数据（53个变量）  
> **工具**：Claude Code (Opus 4.7) + VS Code 扩展 + Python 3.12 + XeLaTeX

---

## 一、项目做了什么

本项目完成了一套完整的**数据分析→建模→报告**工作流，核心亮点是**对比了两种AI使用方式**：

| 方式 | 文件夹 | 说明 |
|------|--------|------|
| **简单Prompt** | `prompt版本/` | 用自然语言对话让AI写代码、生成报告，无额外方法论指导 |
| **Skill增强** | `skill版本/` | 调用专业Skill（数据分析/数学建模/代码审查/论文写作）系统化完成任务 |

两种方式都独立完成了华中杯C题的四个问题（数据特征分析→就业预测→模型优化→人岗匹配），并各自生成了LaTeX技术报告。

最后在 `版本对比与新Skill设计/` 中对两种方式进行了三方对比（以范例报告为基准），并基于实战观察设计了2个新的自定义Skill。

## 四、核心发现

### 4.1 Skill增强的价值（量化）

以范例报告为100分基准：

| 维度 | Prompt版 | Skill增强版 | 提升幅度 |
|------|---------|------------|---------|
| 数据预处理 | 55 | 85 | +55% |
| 统计严谨性 | 30 | 90 | **+200%** |
| 模型评估可靠性 | 35 | 92 | **+163%** |
| 类别平衡处理 | 0 | 75 | 从无到有 |
| 匹配区分度 | 20 | 60 | +200% |
| 代码质量 | 50 | 85 | +70% |
| **加权总分** | **34.5** | **78.5** | **+128%** |

### 4.2 关键教训

1. **简单Prompt最大的坑**：类别不平衡不处理→失业召回率≈0→模型全判"就业"作弊→高F1是虚假的
2. **Skill最大的价值**：不是让AI更聪明，而是**让AI不犯低级错误**（如CV检查、class_weight提醒、特征重要性来源验证）
3. **现有Skill的不足**：各自独立、缺少全流程协调、缺少LaTeX专项支持——这正是我们设计2个新Skill的原因
