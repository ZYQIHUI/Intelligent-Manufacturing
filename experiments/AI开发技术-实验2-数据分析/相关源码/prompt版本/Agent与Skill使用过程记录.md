### 2.2 Skill使用详情

**pdf Skill（唯一显式调用的Skill）**

- **调用目的**：读取加密的范例报告PDF（密码123456），提取文本内容作为参考
- **调用方式**：通过 `Skill` 工具，参数 `skill="pdf"`，传入解密和提取指令
- **遇到问题**：PDF为44页扫描图片版（无文本层），直接提取失败
- **解决过程**：
  1. 使用 `pikepdf` 解密 → 保存为无密码PDF
  2. 安装 `pdf2image` 将PDF页转为图片
  3. 安装 Tesseract OCR (Windows) + 下载中文语言包 `chi_sim.traineddata`（44MB）
  4. 使用 `pytesseract` 逐页OCR提取中文文本
- **结果**：成功提取全部44页内容，获得了参考报告的结构、方法和关键数据

## 3. 工作流程与Prompt策略

### 3.1 整体工作流

```
理解任务 → 数据探索 → 数据预处理 → 问题一分析 → 问题二预测 
→ 问题三优化 → 问题四匹配 → 技术报告撰写 → LaTeX编译
```

### 3.2 各阶段Prompt策略

#### 阶段1：项目理解

**用户Prompt思路**：先查看文件列表 → 读取题目PDF → 读取Excel数据结构 → 读取范例报告

**AI响应方式**：逐文件读取，识别出4个Sheet的数据结构（数据集/预测集/字段注释/行业代码），三层表头格式，`\N`空值标记，以及范例报告的解题思路。

**关键发现**：原始数据无直接就业/失业标签字段，需要通过就业时间和失业时间的时序关系自行构建。

#### 阶段2：数据探索与预处理

**用户Prompt思路**：先做探索（`explore_data.py`）→ 确认数据全貌 → 再做正式预处理（`01_data_preprocessing.py`）

**AI响应方式**：
- 自动识别出23个字段存在`\N`空值标记
- 统计缺失率分层（极端>95%、严重80-95%、高度40-80%等）
- 设计4条标签构建规则（基于时间先后+劳动合同+录用单位兜底）
- 丢弃10列缺失率>80%的字段
- 处理23%缺失的专业字段（新增`profession_has_value`特征）

**迭代次数**：2轮（探索1轮 + 正式预处理1轮）

#### 阶段3：问题一——数据特征分析

**用户Prompt思路**：先捋清步骤 → 确认 → 再生成代码

**AI响应方式**：
- 规划9步分析（总览→年龄→性别→学历→行业→婚姻/户口→相关性→年龄×学历交叉→性别×行业交叉）
- 使用matplotlib+seaborn生成9张图表
- 安装缺失的依赖库（matplotlib、seaborn）
- 中文字体配置（SimHei/Microsoft YaHei）

**遇到的问题**：初次运行汇总输出`hukou_rates.idxmax()`因NaN报错 → 添加`dropna()`保护

**迭代次数**：2轮

#### 阶段4：问题二——就业状态预测

**用户Prompt思路**：确认步骤 → 生成代码 → 运行 → 修复

**AI响应方式**：
- 构建8种分类模型对比框架（LR/DT/RF/KNN/SVM/GBDT/XGBoost/LightGBM）
- 安装scikit-learn、xgboost、lightgbm依赖
- 分层抽样80/20划分，固定random_state=42
- 生成特征重要性条形图、混淆矩阵、模型对比图
- 对预测集20个样本输出预测结果

**遇到的问题**：
- pip安装依赖被路由到后台运行，需等待完成后重新执行
- 预测集"预测"列全为NaN（原始数据即空白，用于填写模型输出）

**迭代次数**：2轮

#### 阶段5：问题三——模型优化

**用户Prompt思路**：确认引入什么数据 → 确认 → 生成代码

**AI响应方式**：
- 构建7项宜昌市2019-2024年宏观经济模拟数据（基于真实趋势）
- 包含2020年疫情冲击的特征波动（GDP-3.2%，招聘指数78）
- 与训练数据按年份合并（ref_year = max(b_acc031, c_ajc090)的年份）
- 在增强特征集上重新训练8种模型，与基础版本对比

**迭代次数**：1轮（运行成功）

#### 阶段6：问题四——人岗匹配

**用户Prompt思路**：确认 → 生成代码 → 运行 → 修复

**AI响应方式**：
- 构建求职者画像（8维）+ 岗位画像（9维含行业编码）
- Min-Max标准化 + 余弦相似度计算
- 相似度矩阵(1134×3846)，Top-5推荐
- 生成匹配分析和行业分布图

**遇到的问题**：
- `industry_name`列不存在 → 改用`industry_category`
- StandardScaler导致余弦相似度均值仅0.002 → 改用MinMaxScaler后升至0.694
- `b_aab004`列引用错误 → 修复列名

**迭代次数**：3轮

#### 阶段7：技术报告撰写

**用户Prompt思路**：先检查模板结构 → 确认 → 生成LaTeX → 编译 → 修复问题

**AI响应方式**：
- 复制模板文件（cumcmthesis.cls、字体、ref.bib）到报告文件夹
- 复制15张图表到figures/目录
- 撰写完整LaTeX报告（封面→目录→摘要→四问→评价→附录）
- 编译完成后根据用户反馈修复3个问题

**遇到的问题**：
1. **无封面页** → 添加`titlepage`环境自定义封面
2. **无目录** → 启用`\tableofcontents`
3. **79页内容重复**（附录完整代码清单导致溢出）→ 改为仅引用关键代码段（`firstline`/`lastline`），压缩至30页
4. **字体编译错误** → 复制Fira Code字体文件，确保XeLaTeX能加载

**迭代次数**：3轮

## 4. Agent使用情况

本次Prompt版本**未大量使用子Agent**，主要采用直接对话模式。原因：

| 场景 | 使用方式 | 原因 |
|------|---------|------|
| 文件搜索 | `Bash` + `Glob` 直接工具 | 项目文件少，无需Explore Agent |
| 代码编写 | `Write` + `Edit` 直接工具 | 每次任务聚焦单一脚本 |
| 依赖安装 | `Bash` 后台运行 | pip install 耗时操作 |
| PDF提取 | `Skill(pdf)` | 调用专业PDF处理Skill |
| 报告撰写 | `Write` 直接工具 | 需要精确控制LaTeX内容 |

**对比预判**：Skill增强版本将使用 `math-modeling` skill 来系统化数学建模流程、使用数据分析专用skill来优化模型调优和特征工程、使用 `Agent` 来并行分发独立任务。

## 6. 简单Prompt版本的反思

### 优势
- **快速启动**：无需提前配置Skill，直接对话即可开始工作
- **灵活迭代**：用户可按需提出修改，AI即时响应
- **透明度高**：每一步生成的代码用户都能直接查看和理解

### 局限性
- **代码质量依赖Prompt质量**：用户需要明确描述需求，否则AI可能走偏
- **缺乏系统性优化**：如类别不平衡问题未被主动解决（AI只在被动响应用户指令）
- **多次人工介入**：语法报错、缺失列名等问题需要人工发现并反馈
- **模型评估不够严谨**：未进行交叉验证、超参数网格搜索等标准化操作
- **图表风格不一致**：各问题独立生成，配色和布局风格不完全统一
