## 二、PromptVersion 目录结构

```
PromptVersion/
├── app.py                  # Streamlit Web 应用主程序
│                           #   - 加载知识库
│                           #   - 构建 RAG 检索链路
│                           #   - 基于 prompt.txt 模板进行问答
│                           #   - 提供 Web UI 交互界面
│
├── build_kb.py             # 知识库构建脚本
│                           #   - 解析 PDF 文档
│                           #   - 提取文本与图像
│                           #   - 向量化并存入 Milvus
│
├── prompt.txt              # 系统提示词模板
│                           #   - 定义 LLM 角色与行为
│                           #   - 包含检索增强指令
│                           #   - 指定回答格式要求
│
├── test_questions.py       # 自动化测试问题集
│                           #   - 预定义测试问题列表
│                           #   - 用于验证 RAG 问答效果
│
├── PChat.md                # Prompt版本对话记录/说明
│
└── README.md               # 版本说明文档
```

**设计理念**：通过精心设计的 Prompt 模板驱动整个 RAG 流程，将检索逻辑、上下文组装、回答生成全部交由 LLM 在提示词引导下完成。

## 三、SkillVersion 目录结构

```
SkillVersion/
├── app.py                  # Streamlit Web 应用主程序
│                           #   - 加载 Skill 模块
│                           #   - 编排检索与生成流程
│                           #   - 提供 Web UI 交互界面
│
├── build_kb.py             # 知识库构建脚本
│                           #   - 调用 pdf_parser 解析 PDF
│                           #   - 调用 embedding_engine 向量化
│                           #   - 调用 vector_store 存储
│
├── config.py               # 全局配置文件
│                           #   - LLM 模型选择与参数
│                           #   - Embedding 模型配置
│                           #   - Milvus 连接参数
│                           #   - 文件路径配置
│
├── pdf_parser.py           # PDF 解析模块
│                           #   - 文本提取
│                           #   - 图像提取与 OCR（如需要）
│                           #   - 表格识别与结构化
│
├── embedding_engine.py     # 嵌入引擎模块
│                           #   - 文本嵌入向量生成
│                           #   - 图像嵌入向量生成
│                           #   - 批量向量化处理
│
├── vector_store.py         # 向量存储模块
│                           #   - Milvus 连接管理
│                           #   - Collection 创建与管理
│                           #   - 向量检索（相似度搜索）
│                           #   - 元数据存储与查询
│
├── test_questions.py       # 自动化测试问题集
│                           #   - 预定义测试问题列表
│                           #   - 用于验证 RAG 问答效果
│
├── SChat.md                # Skill版本对话记录/说明
│
└── __pycache__/            # Python 自动生成的字节码缓存
    ├── config.cpython-311.pyc
    ├── embedding_engine.cpython-311.pyc
    └── vector_store.cpython-311.pyc
```

**设计理念**：将 RAG 系统的各个功能模块（PDF解析、嵌入、向量存储、检索）拆分为独立 Skill 模块，通过模块化组合实现可复用、可配置的 RAG 流程。

---

## 四、两个版本对比

| 维度 | PromptVersion | SkillVersion |
|------|-------------|-------------|
| 文件数量 | 6 个 | 10 个（含 `__pycache__`） |
| 架构风格 | 集中式（Prompt 驱动） | 模块化（Skill 分工） |
| 核心文件 | `prompt.txt` | `config.py` + 4个模块文件 |
| 可扩展性 | 低（修改 Prompt 为主） | 高（独立模块可替换/复用） |
| 可配置性 | 低（硬编码在 Prompt 和代码中） | 高（集中在 `config.py`） |
