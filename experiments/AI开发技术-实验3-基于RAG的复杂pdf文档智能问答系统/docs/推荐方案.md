## 按功能模块的社区 Skill 对照

### 1. PDF 解析 —— 可替代自定义的 `pdf-parser.md`

| Skill | 来源 | 核心能力 |
|-------|------|---------|
| **Knowledge Ingestion Patterns** | mcpmarket.com | 结构感知 PDF 分块、表格自动提取、丰富元数据 schema、上下文保留分块策略 |
| **Document Parsers** | mcpmarket.com | 使用 LlamaParse + Unstructured.io + PDFPlumber，支持 OCR、自动分块、元数据提取 |
| **Anthropic 官方 `pdf`** | anthropics/skills | 提取文本、创建/合并/拆分 PDF、处理表单 |
| **LlamaIndex Claude Code Skill** (384⭐) | mcpmarket.com | 300+ 数据连接器（LlamaHub）、多模态 RAG（图片+非结构化PDF）、自动评估工具 |
| **Skill Seekers** (12.2k⭐) | GitHub | 17+ 种数据源（含 PDF OCR、密码保护PDF、表格提取），一键打包为 Claude Skills / LlamaIndex TextNodes / LangChain Documents |

### 2. RAG 系统 —— 可替代自定义的 `rag-system.md`

| Skill | 来源 | 核心能力 |
|-------|------|---------|
| **rag-implementation** | claude-plugins.dev / mcpmarket.com | 完整 RAG：Dense/Sparse/Hybrid/Multi-Query/HyDE 检索策略、Cross-Encoder/Cohere/MMR Reranking、支持 Milvus/Pinecone/Chroma/FAISS/Qdrant/Weaviate |
| **LlamaIndex Claude Code Skill** | mcpmarket.com | 多模态 RAG、自动评估（回复相关性、忠实度检测）、丰富的索引策略 |
| **RAG Implementation (LLM Knowledge Integration)** | mcpmarket.com | 面向文档问答系统、知识库聊天机器人、带来源引用的研究工具 |

### 3. 向量数据库 —— 可替代自定义的 `vector-db.md`

## 推荐组合方案

| 功能模块 | 推荐社区 Skill | 理由 |
|---------|---------------|------|
| PDF 解析 | **Knowledge Ingestion Patterns** 或 **Skill Seekers** | 专门处理中文表格和结构感知分块，比自定义的更通用 |
| RAG 系统 | **rag-implementation** | 覆盖面最全（检索策略 + Reranking + 多向量库），直接弥补阶段二的不足 |
| 向量数据库 | **rag-implementation** 的 Milvus 部分 | 自带 Milvus 最佳实践，不需要单独找 |
| Streamlit 前端 | **Anthropic 官方 `frontend-design`** + 自定义 Streamlit 特定逻辑 | 社区没有专门针对"RAG Streamlit 聊天界面"的 Skill，前端布局仍需自定义 |

## 与自定义 Skill 的差异分析

| 对比维度 | 阶段二自定义 Skill | SkillVersion 社区 Skill |
|---------|------------------|------------------------|
| 知识来源 | 阶段一调试经验（7个问题） | 社区最佳实践 + 多项目验证 |
| 覆盖面 | 仅覆盖本项目踩过的坑 | 覆盖更广泛的场景和策略 |
| PDF解析 | 手动 PyMuPDF + EasyOCR | 结构感知分块 + 表格自动提取 |
| RAG检索 | 简单均衡采样（text:8 + image:4） | Dense/Sparse/Hybrid + Reranking |
| 向量库 | 基础双集合 Milvus Lite | Milvus 完整配置 + 多库支持 |
| 可复用性 | 仅限本项目同类场景 | 跨项目通用 |
| 维护性 | 依赖个人维护 | 社区持续更新 |

## 补充发现

之前下载到 `E:\LlamaIndex相关的\` 的两个仓库：
- **LlamaIndex-Tutorials**：入门教程（Jupyter notebook），不是 Skill 格式
- **langchain**：完整源码 monorepo，`CLAUDE.md`/`AGENTS.md` 是项目开发规范，不是 RAG 相关 Skill

都不能直接作为 Claude Code Skill 使用。

但社区中存在真正的 Skill 形态产品：
- **LlamaIndex Claude Code Skill**（mcpmarket.com，384⭐）：将 LlamaIndex 的 300+ 连接器和完整 RAG 流程封装为可直接加载的 Skill
- **Skill Seekers**（12.2k⭐）：将 17+ 数据源的摄入过程封装为 Skill
