## 第7页 · 阶段一：7个问题与解决（核心页）

挑 3 个关键问题详解，其余表格带过：

| 问题 | 原因 | 解决 |

## 第13页 · 心得体会（4点）

1. **社区 Skill 解决通用架构，自定义 Skill 解决领域问题** — 两者分工而非替代
2. **组件边界越清晰，调试越容易** — 阶段二从文件名就能定位问题
3. **社区 Skill 生态现状** — 通用框架成熟，细粒度领域（中文金融PDF）仍然稀缺
4. **Agent 不是不聪明，而是缺乏"经验记忆"** — Skill 将踩坑经验持久化，跨项目复用

---

## 第14页 · 总结

- 一句话：单提示词"快"但调试成本高，社区Skill协同让 Agent 少走弯路
- 三个关键数据：
  - 调试次数 **7 → 2**
  - 代码行数 **1100 → 950**
  - 核心 bug **5 → 0**
