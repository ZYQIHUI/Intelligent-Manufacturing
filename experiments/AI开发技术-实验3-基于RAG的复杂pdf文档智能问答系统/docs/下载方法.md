# 社区 Skill 下载方法

---

## 需要下载的 Skill

### 1. rag-implementation（RAG 系统 + Milvus 向量库）

| 项目 | 内容 |
|------|------|
| GitHub 仓库 | `https://github.com/lifangda/claude-plugins` |
| 目标路径 | `SkillVersion\.claude\skills\rag-implementation\` |
| 下载方式 | `git clone` 整个仓库后，只取 `rag-implementation/` 子目录 |

```bash
# 在项目根目录执行
mkdir -p SkillVersion/.claude/skills
git clone https://github.com/lifangda/claude-plugins.git /tmp/claude-plugins
cp -r /tmp/claude-plugins/rag-implementation SkillVersion/.claude/skills/rag-implementation
rm -rf /tmp/claude-plugins
```

---

### 2. frontend-design（Streamlit 前端设计）

| 项目 | 内容 |
|------|------|
| GitHub 仓库 | `https://github.com/anthropics/skills` |
| 目标路径 | `SkillVersion\.claude\skills\frontend-design\` |
| 下载方式 | `git clone` 整个仓库后，只取 `frontend-design/` 子目录 |

```bash
# 在项目根目录执行
git clone https://github.com/anthropics/skills.git /tmp/anthropic-skills
cp -r /tmp/anthropic-skills/frontend-design SkillVersion/.claude/skills/frontend-design
rm -rf /tmp/anthropic-skills
```

> 如果执行 `git clone` 之前就已经在**本地**的某个位置有 `skills` 这个仓库，直接从中复制 `frontend-design/` 目录即可，无需重新下载。

---

### 3. knowledge-ingestion-patterns（PDF 解析 + 表格提取）

`https://mcpmarket.com/zh/tools/skills/knowledge-ingestion-patterns` — 在该页面找到实际 GitHub 仓库地址后下载，目标路径为：

```
SkillVersion\.claude\skills\knowledge-ingestion-patterns\
```

如果找不到 GitHub 地址，可以使用备选方案：

**Skill Seekers**（12.2k⭐）

| 项目 | 内容 |
|------|------|
| GitHub 仓库 | `https://github.com/yusufkaraaslan/Skill_Seekers` |
| 目标路径 | `SkillVersion\.claude\skills\skill-seekers\` |

```bash
git clone https://github.com/yusufkaraaslan/Skill_Seekers.git /tmp/skill-seekers
cp -r /tmp/skill-seekers SkillVersion/.claude/skills/skill-seekers
rm -rf /tmp/skill-seekers
```
